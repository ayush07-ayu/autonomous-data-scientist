# Autonomous Data Scientist

An AI-powered system that automates major parts of the Data Science workflow.

## Project Goal

The system will allow users to upload a dataset and automatically perform:

- Data Profiling
- Data Cleaning
- Exploratory Data Analysis
- Feature Engineering
- Machine Learning
- Model Evaluation
- Prediction
- Explainable AI
- Anomaly Detection
- Automated Insights

Later, an AI Agent will be added to understand natural-language questions and select appropriate tools for data analysis.

## Technology Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- FastAPI
- PostgreSQL
- Streamlit
- LLM
- Tool Calling
- LangGraph
- SHAP
